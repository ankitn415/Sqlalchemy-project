# 🛒 Online Sales Data Analysis with PostgreSQL & Python

This project performs data cleaning, transformation, and exploratory analysis on an online sales dataset using **pandas**, **SQLAlchemy**, and **PostgreSQL**. The goal is to extract monthly sales trends and order volume to support data-driven business decisions.

---

## 📂 Dataset

- **Source**: `Online Sales Data.csv`  
- **Fields Used**:
  - `Transaction ID` → renamed as `order_id`
  - `Date` → renamed as `order_date`
  - `Total Revenue` → renamed as `amount`

---

## ⚙️ Tools & Technologies

- **Python**
- **pandas**
- **PostgreSQL**
- **SQLAlchemy + psycopg**
- **Jupyter Notebook**
